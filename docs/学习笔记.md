## 二、环境修复：`conda activate` 不生效

- 现象：`conda activate srs` 执行后提示符不显示 `(srs)`，`CONDA_PREFIX` 为空
- 排查思路（一步步缩小范围）：环境存在吗 → 初始化代码在吗 → 有没有被执行 → 执行策略拦了吗
- 根因：PowerShell 5.1 的执行策略实际为 **Restricted**（注册表键缺失 = 默认禁止一切脚本），导致 profile 里的 conda 初始化代码在终端启动时就被拦截
- 解决：`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`（允许本地脚本，远程脚本仍需签名），然后**重开终端**才生效
- 附带：PowerShell 7 需要先 `conda init powershell` 生成它自己的 profile
- 经验：Windows 上"命令不生效"先查三件事——PATH 有没有、profile 加没加载、执行策略允不允许脚本

## 三、D2：第一个下载脚本

- 任务：下载通用基线数据 **ChnSentiCorp**（中文情感二分类，7766 条，字段 `label, review`）
- 定位：这是**通用基线**，用来练"下载 → 读取 → 分析 → 建模"整套流程；真正的领域数据是某市景点评论（后续阶段使用）
- 下载脚本"三段式"思维：
  1. **变量**：想清楚"要下什么、存到哪"
  2. **发请求**：真正去拿字节
  3. **校验**：证明真的下到了（文件大小）
- 踩坑记录：
  - hf-mirror 会拒绝 Python 默认请求头（HTTP 403）→ 必须加 `User-Agent` 伪装成浏览器
  - 原始数据保存到 `data/`（已被 .gitignore 忽略，永不进公开仓库）
  - 数据编码为 UTF-8
- 脚本代码（下载 + 保存 + 校验）：

```python
import urllib.request
import os

url = "https://hf-mirror.com/datasets/dirtycomputer/ChnSentiCorp_htl_all/resolve/main/ChnSentiCorp_htl_all.csv"
req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
resp = urllib.request.urlopen(req)
data = resp.read()
print("拿到了字节数:", len(data))

save_dir = "data/raw/chnsenticorp"
save_path = os.path.join(save_dir, "ChnSentiCorp_htl_all.csv")
os.makedirs(save_dir, exist_ok=True)

with open(save_path, "wb") as f:
    f.write(data)

size = os.path.getsize(save_path)
print("文件大小:", size)
print("是否等于 2904858:", size == 2904858)
```
